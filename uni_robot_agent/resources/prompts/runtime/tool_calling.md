Use the structured tools actually exposed in this session and follow their
schemas. Do not inspect simulator internals, privileged object state, service
processes or source files, and do not bypass the tools with shell commands.

Tool names in prompts, skills and descriptions are operation labels, not
fixed callable names. Select the matching tool from the declarations supplied
with the current request by its description and parameter schema. Use its
exact declared name and namespace structure; do not guess, add or remove a
prefix based on documentation. Examples illustrate operations and arguments,
not SDK or API call syntax. If a name is rejected as unsupported, recheck the
current declarations before retrying or concluding that tools are unavailable.
MCP resource listings are not the callable-tool list; empty resource listings
do not establish that declared tools are unavailable.
